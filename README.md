# Тестовое задание: сервис ДДС

В репозитории реализовано Django-приложение для учёта движения денежных средств:

- CRUD для записей ДДС
- фильтрация по периоду, статусу, типу, категории и подкатегории
- CRUD для справочников
- валидация связей `тип -> категория -> подкатегория`
- API на Django REST Framework
- стартовые справочники через миграцию

## Стек

- Python 3.14
- Django 6
- Django REST Framework
- SQLite

## Запуск

1. Создать и активировать виртуальное окружение:

```bash
python3 -m venv .venv
source .venv/bin/activate
```

2. Установить зависимости:

```bash
pip install -r requirements.txt
```

3. Применить миграции:

```bash
python manage.py migrate
```

4. Запустить сервер:

```bash
python manage.py runserver
```

После запуска приложение будет доступно по адресу `http://127.0.0.1:8000/`.

## Что уже настроено

- После `migrate` автоматически создаются стартовые статусы, типы, категории и подкатегории.
- Реестр операций доступен на `/`.
- Управление справочниками доступно на `/references/`.
- REST API доступно на `/api/`.
- Django admin доступен на `/admin/`.

## Тесты

```bash
python manage.py test
```

## Основные сущности

- `Status`
- `OperationType`
- `Category`
- `Subcategory`
- `CashFlowEntry`

## Бизнес-правила

- сумма должна быть больше нуля
- категория обязана принадлежать выбранному типу операции
- подкатегория обязана принадлежать выбранной категории
- валидация работает и в формах, и в API
